# 方块之间 · BLOCKFALL

完整的桌面俄罗斯方块游戏。原生 HTML / CSS / JavaScript，无依赖、无安装、无构建，可离线游玩。

## 启动

**最简单：解压后，用 Edge、Chrome 或 Firefox 打开 `index.html`，点击「开始游戏」。** 不要在压缩包里直接打开，请先解压整个文件夹。页面中的 CSS、JS 和 SVG 文件需要留在原来的相对位置。

可选：如果电脑已安装 Node.js，在本文件所在目录打开终端并运行：

```sh
node serve.cjs
```

然后访问 `http://127.0.0.1:4173`。按 Ctrl+C 停止服务器。也可以使用 `npm start`，不需要 `npm install`。

## 操作

| 按键 | 功能 |
| --- | --- |
| ← / →（或 A / D） | 左右移动；按住可连续移动 |
| ↑ / X（或 W） | 顺时针旋转 |
| Z | 逆时针旋转 |
| ↓（或 S） | 软降；按住加速，每下降一格 +1 分 |
| 空格 | 硬降，直接固定在投影位置；每下降一格 +2 分 |
| C | 暂存 / 交换方块，每个下落方块限一次 |
| P / Esc | 暂停 / 继续 |
| Enter | 从开始或结束界面开始新局；暂停时继续 |
| M | 音效开关，默认关闭 |
| Shift + /（?） | 打开玩法与计分说明 |

「重新开始」按钮立即清空当前局并开始新局。窗口失去焦点或页面进入后台时自动暂停，返回后按 P 或点击「继续游戏」恢复。打开玩法说明也会暂停，关闭说明后手动继续。

## 游戏规则

- 可见棋盘为 10 列 × 20 行，顶部另外保留 2 个隐藏行。
- I、O、T、S、Z、J、L 七种方块，颜色各不相同。使用 7-bag 随机袋：每袋七种各一块，打乱后依次抽取。
- 预览接下来 3 个方块，细线投影显示当前方块的落点。
- 旋转使用 SRS 踢墙规则：在墙边和地面附近尝试合法偏移；无合法位置时保持原状。O 方块旋转不改变形状。
- 方块接触地面或堆叠后，有 500 毫秒固定延迟，允许继续调整。落地后的有效移动或旋转最多重置延迟 15 次；无效操作不会重置。硬降立即固定。
- 同时填满的所有整行一起消除，上方方块下移。每累计消除 10 行升一级。
- 第 1 级自动下落间隔 900 毫秒；每级乘以 0.8，最低 65 毫秒。软降采用更短的间隔。
- 新方块出生位置被阻挡，或固定并消行后隐藏行仍有方块时，游戏结束。

| 单次消行 | 基础分（再乘以消行前的等级） |
| --- | ---: |
| 1 行 | 100 |
| 2 行 | 300 |
| 3 行 | 500 |
| 4 行 | 800 |

连续有消行的方块，从第二个开始增加连击分：`50 × 连击索引 × 当前等级`，第二次索引为 1。无消行的方块会清除连击。

上次消行和本次消行都是四行时，本次额外获得 50% 的基础分。中间可以有不消行的方块；消除 1～3 行会中断这项奖励。软降与硬降分数不乘等级。本版本不设置 T-spin、全清或特殊旋转的额外计分。

## 上传 GitHub Pages

1. 新建一个 GitHub 仓库，将 **此文件夹内的内容** 上传到仓库根目录。确保根目录直接能看到 `index.html`，而不是外面还套一层 `tetris/`。不要只上传 ZIP 文件。
2. 至少上传 `index.html`、`styles.css`、`engine.js`、`game.js`、`favicon.svg` 和 `.nojekyll`；也可以上传整个项目。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
5. 选择实际上传文件的分支（通常为 `main`）及 **/(root)**，点击 **Save**。
6. 等待仓库的 Pages 部署任务完成，再打开 Pages 设置页给出的链接。项目地址通常为 `https://你的用户名.github.io/仓库名/`。

本项目使用相对路径，放在 GitHub Pages 的仓库子路径下也可以运行，无需修改代码或添加构建流程。若出现 404，先检查根目录中的 `index.html`、分支和文件夹选择，再查看仓库 Actions 中的部署结果。

发布设置参考：[GitHub 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。本次交付为本地文件，未代替你上传仓库或开启线上站点。

## 文件作用

| 文件 | 作用 |
| --- | --- |
| `index.html` | 中文页面结构，棋盘、分数、暂存、预览、开始/暂停/结束界面与玩法对话框 |
| `styles.css` | 暗色桌面布局、方块界面、屏幕高度适配、按钮与消行动画、减少动态效果支持 |
| `engine.js` | 独立规则引擎：随机袋、移动、双向旋转、碰撞、投影、固定、消行、计分、等级和结束判断 |
| `game.js` | Canvas 绘制、键盘长按、界面状态、自动暂停、可选音效、最高分与偏好保存 |
| `favicon.svg` | 浏览器页签图标 |
| `.nojekyll` | 让 GitHub Pages 按静态文件处理项目 |
| `serve.cjs` | 可选的 Node.js 本地预览服务器，仅监听当前电脑的回环地址 |
| `package.json` | 项目名称与版本，`npm start` / `npm test` 快捷命令，无第三方依赖 |
| `tests/engine.test.cjs` | 可重复运行的规则测试，包括边界场景及 30,000 次随机操作检查 |
| `PROJECT-PLAN.md` | 项目结构、技术方案、实现顺序与功能规划 |
| `TEST-REPORT.md` | 实际执行的测试、结果与验证范围 |
| `README.md` | 当前说明文档 |

## 运行测试

安装 Node.js 18 或以上版本后，在本文件所在目录运行：

```sh
node --test tests/engine.test.cjs
```

或者运行 `npm test`。测试不需要安装依赖。玩游戏本身不需要 Node.js。

## 兼容性和保存

- 面向现代桌面浏览器，需要 JavaScript、Canvas 2D、`dialog`、`ResizeObserver` 和 `roundRect` 支持。推荐使用近期版本的 Edge、Chrome、Firefox 或 Safari。
- 所有资源随项目附带，无字体下载、图片下载或外部接口。音效由 Web Audio 本地生成，默认关闭。
- 最高分与音效偏好保存在当前浏览器的 localStorage；浏览器禁止存储时仍可玩，但记录可能无法跨刷新保留。`file://` 下存储行为由浏览器决定，换电脑、浏览器或网址后记录不会共享。
- 不保存正在进行的棋盘；刷新会回到开始界面。音效的实际播放取决于系统输出设备和浏览器声音设置。
- 棋盘主要通过视觉和键盘操作；菜单具备键盘焦点和状态播报，但未实现供屏幕阅读器完整游玩的逐格棋盘导航。
- 仅为桌面端设计，没有触屏控制或联网排行榜。
